# Translations

Ten locales: deDE, esES, esMX, frFR, itIT, koKR, ptBR, ruRU, zhCN, zhTW. The game client's locale is used; a language picker was
built and then removed on purpose.

- English is the key in code; every string also has a stable numeric ID (`tools/locale_registry.json`, append-only). Locale
  files are generated by `tools/locales.py` as `ID -> text` with a `-- <hash> English:` comment above each translation; never
  edit headers, hashes or IDs by hand. Use `tools/translation_status.py`, `translation_todo.py` and `translation_apply.py` (workflow:
  `docs/translators/README.md`). Glossary and per-language register: `docs/translators/glossary.md` and `style.md`.
- **AI-assisted translation is allowed**, as a draft: validation (placeholders, color codes, line breaks, length, identical-to-
  English) is mandatory; give the model the glossary and style guide; small batches; no personal data; state in the commit
  message whether a native speaker reviewed it, and do not claim a review that did not happen. Do not guess game terms.
- Registers (measured): German formal Sie; French vous; Spanish (both) informal tú; Italian tu; Portuguese você; Russian Вы;
  Korean polite -합니다/-세요; Chinese 你. Details in `style.md`.
- Terminology: *Identifier* (short *ID*), never "Handle" or "Identity". *Built In*, *Priority*, *Switch*, *Stop*, *Branch*.
- Change English with `python3 tools/locales.py reword "old" "new"`: the ID and every translation stay (stale by hash, still
  shown; `locales.py missing <xx>` lists them, `accept` blesses a typo fix). Add a new string (`add`/`sync`) when the meaning
  changes. Never hand-edit `Locales/enUS.lua`.
- Credit translators with `--translator "Name"` (header + About page for humans); the AI is named in the header only.
  Strings with placeholders and short strings carry notes/context (`locales.py notes`); `where` finds a string's uses.
- Keep `Locales/enUS.lua` at or below 3,900 entries; text read only on demand lives in the load-on-demand text bundles, whose
  strings must be translated in all ten locales (`learnings/tests-and-locales.md`, `docs/dev/architecture.md` "Text bundles").
  The tools treat the main catalog and the bundles as one language.
- American spelling in English text, enforced by `tests/test_us_spelling.py`.
