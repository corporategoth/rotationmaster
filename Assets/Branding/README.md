# Rotation Master logo

The selected first design (tri-school rotation) is the source artwork in `rotation-master.png`. It retains transparency. The game uses the 256×256 RGBA TGA export in `rotation-master.tga`; `addon.logoTexture` in constants.lua is the shared reference for headers, dialog chrome, the Settings launcher, and the data-broker/minimap icon.

Resize the PNG with alpha preserved to regenerate the TGA. No runtime image-generation or third-party addon is needed.
