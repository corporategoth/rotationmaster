# Profiles

A **profile** is a complete set of Rotation Master settings: your rotations, General settings, condition categories, profile item sets and announcements. Characters can share a profile or each use their own. (Effects and global item sets are shared by every profile.)

## The Profiles tab

Selecting a profile in the list only **inspects** it. To change which one is in use:

- **Activate profile** switches to the selected profile immediately, including its rotations and settings. The profile in use is marked *Active profile*.

## Creating profiles

- **New** opens a name form; **Duplicate** copies the selected profile into a new one. Names must be unused and at most 50 characters. **Apply** creates it, **Cancel** abandons it.
- Creating a profile does not switch to it. Use **Activate profile** when you want to.

## Copy and reset

These replace the **active** profile, after you confirm:

- **Copy from profile** copies another profile's settings and rotations into the active profile. It does not switch profiles or rename anything.
- **Reset current profile** replaces the active profile with the defaults. Your custom rotations and settings in it are replaced.

Both happen as soon as you confirm. There is no Apply step to undo them, so consider exporting first.

## Deleting

The red trash can permanently deletes the selected profile after confirmation. The active profile and the *Default* profile cannot be deleted.

## Importing and exporting

**Import/Export** turns a profile into text you can save or share, and back.

- Importing as a **new** profile opens a creation draft; give it an unused name and Apply.
- **Replacing** the selected profile happens as soon as you confirm the import. Replacing the active profile applies the imported settings straight away.

**Compare** shows the differences between two profiles' settings without changing either.

> **Tip:** Exporting your profile is a simple way to back up everything before a big change.
