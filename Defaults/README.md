# Packaged rotations

Definitions in this folder are addon data and read-only in game. They always appear in the rotation list, including disabled and inapplicable definitions. Enable preferences live in the profile's `rotationLibrary.preferences`. Clone creates an independent per-spec custom body in the existing SavedVariables rotation store; `rotationLibrary.origins` keeps its manifest, source revision, baseline and step origins. The default is never copied into that editable store automatically. Editing a clone cannot alter its source. Changing profiles rebinds preferences; no source pack overwrites saved rotations or the user's existing fallback.

The first pack is **TBC Shaman early leveling, levels 1–19**, a preview of the authoring/runtime path, not the completed all-class corpus. It uses independent optional highlights for missing weapon imbue and Lightning Shield, plus a Lightning Bolt opener, Earth Shock and a stationary ranged Lightning Bolt filler in the sequential priority. Missing upkeep never blocks a damage recommendation. Known-spell guards skip untrained abilities. Actions use the existing rank expansion/highlighting path; numeric buff IDs cover both Lightning Shield ranks in this range without depending on English spell names. Existing temporary weapon enchants are respected. Spell usability/resources/range and actual action-bar availability are checked by the engine; this pack does not cast actions automatically.

This deliberately modest starter does not encode healing/interrupt overrides, consumables, totem placement, movement-aware openers, enemy time-to-live, Flame Shock weaving, automatic selection of the five-second-rule refresh window (upkeep remains an optional reminder), or later talents/spec rotations. It stops applying at level 20. Revision3 adds the requested ranged filler: native Attack range is preferred; if unavailable, a conservative LibRangeCheck five-yard interval is used. An uncertain interval never becomes a positive beyond-melee match. Normal spell range/usability still applies to the suggested Bolt. This ranged adaptation is RM behavior requested during live testing, rather than a claim that the source guide prescribes that exact decision graph. Do not extrapolate it to max level, dungeons, PvP or other editions. Those remain separate sourced corpus work. Source review and offline scenarios do not establish live recommendation quality or optimal DPS. In-game leveling/rank/highlight verification remains outstanding.

Its guidance was checked against [Icy Veins' original Enhancement leveling guide](https://www.icy-veins.com/tbc-classic/enhancement-shaman-leveling-guide) on 2026-10-17 (page revision 2026-01-12). The implementation adapts the guide's upkeep, pull and shock priorities into a small starter. Spell identity/rank references are recorded in the manifest. No guide prose or complete guide was reproduced. Rank 1 Lightning Shield is learned at level 8; rank 2 at 16. Exact learned state, rather than an assumed training level, controls whether an action can appear.

Authoring requirements: version 1 envelope, stable pack ID/revision and step IDs, explicit edition/action context, localized name/description keys, provenance and independent condition tables. Class/spec may be omitted for shared packs. Unknown condition/schema/edition data remains visible but unavailable for execution. Roles, intent and ruleset selectors currently remain reference-only until their context providers are implemented; do not silently treat them as universal. Retail/Forever defaults remain reference-only under the current restricted-data policy.

Run `python3 tools/check`. `tests/defaults.lua` loads real predicates and the shipped pack, checks structural resolution/localization/source scope, and exercises untrained abilities, upkeep, both shield ranks, combat and friendly targets. This is the starting fixture for a broader corpus scenario suite. The current options view is a temporary AceGUI browser; the compact roster/editor redesign is still planned.

Revision5 supersedes revision4's optional Attack reminder. Weapon Attack is now a universal implicit final sequential fallback: after no earlier action qualifies, in living hostile melee combat with inactive autoattack and all normal action checks satisfied. The engine never inserts a saved step or operates a button. A matching Stop ends lower priorities; the fallback remains eligible unless explicitly suppressed. An unavailable Stop guard suppresses both. Optional upkeep remains independent. Explicit same-action known checks were removed from this pack because every spell action now requires learned state, resources, cooldown and range automatically. Cross-action checks remain available. Existing clones retain their authored steps; compare against the current source to remove an older optional Attack if desired. Actual Attack-button identification/highlighting remains a client test.

Revision6 adds a Stop-if-not-in-combat boundary immediately after the pull opener. Combat priorities below it no longer repeat the player-combat predicate. Stop permits the implicit melee fallback unless its new suppression option is enabled; the fallback still independently requires player combat, so it cannot propose a new pull after the pre-combat boundary. Existing clones retain their prior authored conditions.
