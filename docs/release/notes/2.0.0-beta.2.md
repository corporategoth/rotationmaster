## Highlights

- Mists Classic now loads its matching addon metadata and supports WowLua as an optional Lua editor.
- The Lua editor lists WowLua and LuaWorkbench even when they are not loaded.

## Fixed

- Missing development version metadata no longer stops startup or breaks the minimap tooltip.
- The rotation list shows all specializations correctly when the current specialization is absent from its filter.
- Mists specialization-group detection and the rotation editor's Apply and Discard state are corrected.
- Line numbers work without LuaWorkbench; the native gutter avoids clipping the cursor.
- WowLua syntax colors refresh while editing. LibSharedMedia is updated to CurseForge revision r184.

## Known issues

- LuaWorkbench integration requires its isolated editor API, which is not present in the public 1.2.2 release. RM falls back to the native editor when the API is unavailable.
- WowLua's published Mists TOC declares interface 50500, so newer Mists clients may mark WowLua outdated.
- Other supported clients and addon integrations still need in-game coverage; see the beta guide.

## Upgrading

- Back up the RotationMaster saved variables before upgrading from 1.x. Install every addon folder from the package.
