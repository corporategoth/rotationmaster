## Highlights

Rotation Master 2.0 is a rewrite of the 1.x addon, built around a new in-game rotation editor.

- **A new rotation editor.** Cards and a tree, a rotation library with Class and Character scopes, tags and search, drafts with undo and redo, and Compare and Preview for imported rotations.
- **Built In rotations.** Ready-made rotations for Classic Era / Season of Discovery, TBC Anniversary, Mists, Forever and Retail, shipped as one load-on-demand add-on per class. Enable, disable and re-prioritize them per profile.
- **Many more conditions.** Talent trees by name, a talent picker, Branch and Stop steps, a live "currently matches" bar, raid marker conditions and units, a Set Mark step on Classic-family clients, and custom Lua conditions with a code editor.
- **Retail and Forever support.** The game's restricted combat data is handled explicitly: a condition reads what the game allows, shows as unavailable, or does not exist on that client.
- **Sharing.** Import and export rotations, item sets, announcements and effects. A rotation that uses a condition your client does not have imports disabled, with the condition kept, so you can replace it instead of rebuilding.
- **Faster.** An idle gate, a leaner evaluation engine and far less garbage per poll.
- **Integrations.** Masque, Questie, boss-mod timers, more action-bar addons, and tooltips that show your item sets and rotations.
- **Ten languages**, following the game's language. Translations are AI-assisted and have not been reviewed by native speakers.

## Known issues

- Direct Set Mark has been verified on TBC; the other marker features and some client and addon-integration combinations have had less real-client testing. See the client support table in the repository.

## Upgrading

- Install the whole package: `RotationMaster` and every `RotationMaster_*` folder.
- Back up `RotationMaster.lua` from your `SavedVariables` folder first. Your data is converted on first load and the conversion cannot be undone.
- Rotations saved by 1.x are kept in an archive and do not run until you adopt them (Rotations, then Recover unassigned rotations). Rotation Master tells you once in chat and in a banner in the settings window.
- To go back to 1.x, remove all of those folders, restore your backup and install 1.4.3e.
