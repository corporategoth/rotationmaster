## Highlights
- A new rotation editor: cards and a tree, a rotation library with Class and Character scopes, tags and search, drafts with undo and redo, and Compare, Preview and Check for imported rotations.
- Built In rotations for Classic Era / Season of Discovery, TBC Anniversary, Mists, Forever and Retail, shipped as one load-on-demand add-on per class. Enable, disable and re-prioritize them per profile.
- Many more conditions, talent trees by name, a talent picker with a "Show talent tree" window (Retail, Forever), Branch and Stop steps, a live "currently matches" bar and custom Lua conditions with a code editor.
- Raid marker conditions and units, plus a direct Set Mark step for Classic-family rotations. Mark-dependent features and Set Mark are disabled on Retail and Forever.
- Retail and Forever support, with the game's restricted combat data handled explicitly: a condition reads what the game allows, shows as unavailable, or does not exist on that client.
- Faster: an idle gate, a lean evaluation engine and far less garbage per poll.
- Integrations: Masque, Questie, boss-mod timers, more action-bar addons, and tooltips that show your item sets and rotations.
- Ten languages, following the game's language.

## Known issues
- This is a beta. Most of it has run only against models of the game clients; see the beta guide for what has not been tried in a real client.
- Direct Set Mark has been verified on TBC; the other marker features and the German picker and list layout need more real-client testing. Translations are AI-assisted and have not been reviewed by native speakers.
- Your saved data is converted on first load and the conversion cannot be undone. Back up `RotationMaster.lua` from your `SavedVariables` folder first.
- Rotations saved by 1.x are kept in an archive and do not run until you adopt them (Rotations, then Recover unassigned rotations; adopt one, or all at once for your class). Rotation Master tells you once in chat and in a banner in the settings window.

## Upgrading
- Install the whole package: `RotationMaster` and every `RotationMaster_*` folder.
- To go back to 1.x, remove all of those folders, restore your backup and install 1.4.3e.
