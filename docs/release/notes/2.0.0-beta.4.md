## Highlights

- The addon list now reads properly: Rotation Master and its modules appear as one family with a category, icon and colored names. A copyright comment at the top of every TOC had made the client ignore its fields, which also left the About version blank and settings unsaved on a packaged install.
- Unsaved changes are easier to see and to keep. Modified cards get a rounded pink border, list rows get a pink bar at once, and leaving a rotation offers Keep Unsaved beside Apply and Discard.
- Incomplete rotations and conditions can now be saved. They stay unselectable and show as errors; only a bad identifier stops a save, and a rotation's name never does.

## Changed

- Conflicts are named plainly: two rotations conflict only when both can match and have the same priority. A violet bar and a short "Conflict detected" tooltip say so; ties go by identifier.
- List rows show their problem, conflict and unsaved state as bars in a fixed order, each with a colored tooltip header. The switch condition lists its markers the same way, with a live-check dial beside it.
- The minimap and Titan menu list Automatic Switching (gold), rotations by priority, then Default (green); switched-off rotations are not listed.
- Class modules load only on clients that have the class. Specialization Names appear only where talent groups need them.
- A branch can be dragged by its whole frame in list view. Footers line up across the Rotations, Conditions and Functions tabs.
- Unused libraries (AceComm, AceBucket) were removed. Releases announce on Discord with their notes when a webhook secret is configured.

## Fixed

- Moving a card marks only that card as changed, not every card after it.
- The title shown to other addons keeps its version; Rotation Master's own screens no longer show it twice.

## Known issues

- Other supported clients and addon integrations still need in-game coverage; see the beta guide.
- Translations of the changed help lines are marked stale until translators update them.

## Upgrading

- Back up the RotationMaster saved variables before upgrading from 1.x. Install every addon folder from the package.
