## Highlights

- A rotation that uses a condition your client does not have can now be imported instead of being refused whole. Pressing Import lists those conditions in plain words and offers Import anyway. The conditions are kept exactly as imported, the rotation is saved disabled and unselectable, and you replace them in the editor instead of rebuilding the rotation from scratch.

## Changed

- Pressing Import on a rotation that cannot go ahead now says why in a window of its own, with each problem named by where it is in the rotation. The rotation Import window no longer has a Check import button; the other import windows keep theirs.
- The read-only import preview no longer shows Apply, Discard or View Changes, which could never do anything there.
- A condition that is switched off in Settings, whose custom function is unavailable, or that can never run on this client is treated the same way as an unknown one. Unresolved item sets, effects and Set Mark steps still block an import.

## Known issues

- Other supported clients and addon integrations still need in-game coverage; see the beta guide.
- Translations of the new Import window text are AI-assisted drafts and have not been reviewed by a native speaker.

## Upgrading

- Back up the RotationMaster saved variables before upgrading from 1.x. Install every addon folder from the package.
